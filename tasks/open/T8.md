# T8 — The packaged app is signed without the hardened runtime

**Priority:** Non-blocking proposal. Needs the user's decision and manual checks.

- **Evidence:** Validated on 2026-11-17. `codesign -dv` on the Release product of [package.sh](../../package.sh) reports `flags=0x2(adhoc)`, without the `runtime` flag. [project.yml](../../project.yml) sets no hardened-runtime option and no entitlements.
- **Benefit, a design judgment:** The hardened runtime refuses injected libraries and the attach of a debugger. The app holds API keys in memory and reads them from the Keychain.
- **Expected outcome:** The Release build that `package.sh` makes enables the hardened runtime. The Debug build and the hosted tests stay as they are.
- **Not verified:** The review did not build a hardened app. Nobody has shown that such a build launches, reads its Keychain items, plays audio and registers its Service under an ad-hoc signature.
- **Non-goal:** App Sandbox. It would change where the Keychain items of the app live, so it needs its own decision.
- **Validation:** `codesign -dv` shows the `runtime` flag on the packaged app. The user runs the manual smoke checks of README against that build.
- **Dependencies:** The user's decision.
