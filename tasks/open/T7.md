# T7 — One command runs both gates from a clean state

**Priority:** Non-blocking tooling proposal. Needs the user's decision, because S10 (verifier size) questions the amount of tooling.

- **Evidence:** Validated by inspection at `01e94f3` on 2026-11-17. A gate run takes four manual steps: delete the derived data, run `xcodegen generate`, run the Debug build, and run `./check-coverage.sh`.
- [AGENTS](../../AGENTS.md#validation-and-review) says that the build gate disables signing. The build command in [README Build](../../README.md#build) does not, and 32 completion records add `CODE_SIGNING_ALLOWED=NO` by hand.
- README asks the agent to clear the derived data before a warning-free claim. No tool enforces it. An incremental build hides the warnings of the files that it did not recompile.
- **Expected outcome:** One script runs the four steps and the documentation check. It fails on a source warning, and it prints the environment line that a completion record needs.
- README and AGENTS then name the script and drop the prose that it enforces, as the [governance rules](../../AGENTS.md#governance-files) ask.
- **Trade-off:** Keep the script small. Give it a few negative checks and no verifier of its own, so that it does not add to the concern of S10.
- **Validation:** A seeded source warning, a missing SwiftLint and a failing test each fail the script. The benign AppIntents warning does not.
- **Dependencies:** The user's decision. The AGENTS edit is a governance edit, so the user reviews its diff.
