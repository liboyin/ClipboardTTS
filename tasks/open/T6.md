# T6 — Gemini's endpoint is fixed in DESIGN but caller-supplied in the request path

**Priority:** Non-blocking simplification.

- **Evidence:** Validated by source inspection at `01e94f3` on 2026-11-17. `requestEndpoint` in [the request builder](../../Sources/Managers/TTSNetworkManager+Requests.swift) builds the Gemini URL from `settings.baseURL`. For OpenAI it ignores that value and uses the fixed endpoint.
- Two files write the Gemini root: [SettingsView](../../Sources/Views/SettingsView.swift) and [the launch resolution](../../Sources/Managers/TTSNetworkManager+RequestSettings.swift).
- No production caller passes another root today, so no key leaves Google's host. The guarantee rests on the callers and not on the request path.
- **Related:** The model joins the path as typed. A Foundation probe on 2026-11-17 showed that `?`, `#` or `/` in the model changes the path or the query. The host stays fixed.
- **Expected outcome:** One declaration owns the Gemini root. The request path uses it whatever `baseURL` a caller supplied, as it does for OpenAI. It encodes the model as one path segment.
- **Compatibility:** 20 test call sites pass that root as `baseURL`, and they keep working. A test that passes another Gemini root needs a new expectation.
- **Validation:** A test passes a foreign root with the Gemini provider and asserts Google's host. Mutation evidence covers a revert.
- **Dependencies:** None.
