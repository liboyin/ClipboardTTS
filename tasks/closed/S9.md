# S9 — Make clipboard reading a plain value

**Outcome:** Done: the clipboard reader is a plain value the app and menu hold directly, with no SwiftUI ownership or observation, and its unused `ApplicationServices` import is gone.

**Origin:** the second full-project review of 2026-11-03 (TODO Evidence provenance) found `TextExtractionManager` to be an `ObservableObject` with no published state, held as a `@StateObject` and an `@ObservedObject`, importing `ApplicationServices` without using it. On 2026-11-15 the user invoked grouped task execution for the Simplification proposals and chose S5, S6, and S9; S9 was committed first.

## Accepted boundary

The boundary was kept in the group's working review record.

- **Intent:** `TextExtractionManager` becomes a stateless `struct` holding its injected `PasteboardReading`. `ClipboardTTSApp` stores it as a plain `let`, `MenuBarView` takes it as a plain `let`, and the unused import is removed.
- **Compatibility surface:** the clipboard contract is preserved: the 0.2-second deferred read, the empty-clipboard refusal, the injected reader, and the production `GeneralPasteboardReader`. Menu, Settings, Services, persistence, provider-request, and audio-session contracts are untouched.
- **Non-goals:** no rename; `SpeechSessionCoordinator`, `ServicesCoordinator`, and `DeferredClipboardAction` keep their `@StateObject` ownership; the hosted-test startup branch's reader is unchanged.
- **Validation and done:** the build confirms the import is unused, existing clipboard and menu tests pass unchanged, and mutation evidence covers the empty refusal and the menu's read. The gates pass, and the change is reviewed and archived.

**Revalidation at `7d72ed0`:** the class had no `@Published` or mutable state, and its only use was `getCopiedText()` inside the menu's deferred action. First-wins `@StateObject` lifetime only matters for an object with identity or state; every instance startup builds is stateless and reads the same production pasteboard, so a rebuilt `App` value holding a new one is indistinguishable.

## Implementation

**S9 — Done.** The main agent made the change directly; at a few lines, an implementation agent's handoff cost was not justified.

- `TextExtractionManager` is a `struct` with a doc comment saying why it is a plain value; `import ApplicationServices` is removed.
- `ClipboardTTSApp` holds it as `private let textExtraction`, with a comment explaining why it needs no first-wins lifetime. The `servicesCoordinator` comment no longer counts the `@StateObject`s ("all four").
- `MenuBarView.textExtraction` is a plain `let`.

No test changed. DESIGN's Text paragraph describes the reader's contract, not its ownership, and stays accurate.
