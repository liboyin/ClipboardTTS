# T1 — Use the shared documentation, snapshot and dispatch tools

**Outcome:** Done (D42). The review skill and the documentation check use three tools from the checkout of the shared tools repository.

## Origin and boundary

The user requested this ad-hoc change on 2026-11-16, after the restructure that D40 records.

- **Intent:** replace the manual snapshot contract and the inline reviewer commands with tested tools, and check the documentation with a tool.
- **Dependencies:** D42 (the tools run from `../agent-workflow-common`) and D41 (task IDs).
- **Implementation direction:** name the three tools by their path in the checkout, and add `agent-workflow.json`. Copy no tool into this repository.
- **Compatibility surface:** none of the app. No source, test or build configuration changes.
- **Non-goals:** `mutate.py` and `worktree_gates.py` of the reference project. `run-mutants.py` keeps its role.
- **Validation:** one run of each tool from this repository, on the Python that macOS provides.
- **Done:** each tool ran, and the governance files name the tools.

## Implementation

- `agent-workflow.json` sets the files that are checked on changed lines only, the task ID pattern, the two exempt records and the safety rule of the dispatch prompt.
- AGENTS.md gains the documentation check and the rule for shared tools. STYLE.md and the task rules name the check.
- The review skill runs `snapshot.py` and `dispatch.py` of the checkout. Its manual snapshot contract and its inline `codex exec` commands are removed.
- README gains the sections Documentation Check and Shared Tools, and the requirement of the checkout.
