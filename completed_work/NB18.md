# NB18 — Pure tests inherit heavyweight integration dependencies

**Origin:** Non-blocking finding NB18 from the 2026-09-06 full-project review (construction trace): secret-store and Settings secret-state tests inherited the global mock-network lifecycle, and an About test created audio and network managers solely to forward metadata. Executed on 2026-10-12 as the second task of a group with [NB31](NB31.md), which shares the invariant that each test owns exactly the network/session dependencies it needs.

**Boundary:** pure secret-store, migration, Settings secret-state and About tests run on plain `XCTestCase` with owned in-memory dependencies and construct no `TTSNetworkManager`, `AudioPlayerManager`, URL session, speech session or hosted view; cases that genuinely wire a manager or a hosted form stay in small `MockURLProtocolTestCase` wiring suites. Every existing assertion is retained or accounted for, and a mutant breaking `SettingsView.showAbout()`'s forwarding must still fail a retained test. Test-only: no production change. Non-goals: NB17, other suites inheriting `MockURLProtocolTestCase`, `HostedSettings`, and production code. Dependency: lands after NB31.

**Revalidation:** at `34907d4`, `SettingsSecretStateTests` built no manager but inherited `MockURLProtocolTestCase`; nine of the ten `SecretStoreTests` cases were pure; and `testAboutActionPassesInjectedBundleMetadataWithoutPresentingSystemUI` built a `SettingsView` with managers and a speech session only to call `showAbout()`.

**Change:**

- `SettingsSecretStateTests` now inherits `XCTestCase`, keeping all 11 tests.
- `SecretStoreTests` now inherits `XCTestCase` and keeps 9 tests. Its one manager-building case, `testStartupPublishesMigrationFailureWhilePreservingLegacySecret`, moved to `MigrationStartupWiringTests`, a `MockURLProtocolTestCase` in the same file.
- `SettingsAboutTests` now inherits `XCTestCase` without `@MainActor` and keeps 4 tests: two metadata tests, the license test, and the About action test. That action test now calls `AboutAction.showAbout()` directly, keeping its name and both presenter assertions. Its WHY comment now names the hosted button test as the proof of the form's forwarding.
- The hosted About-button test moved to `SettingsAboutButtonWiringTests`, an `@MainActor` `MockURLProtocolTestCase` in the same file, where it can keep using the file-private About doubles.
- Every other assertion and WHY comment moved with its test unchanged.
