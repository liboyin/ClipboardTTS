# S1 — The build enforces SwiftLint

**S1 — Done (user decision, 2026-09-24).** The app target's SwiftLint build step already ran `swiftlint --strict` over `Sources` and `Tests` on every build, so the standalone lint gate added only one guarantee: failing when SwiftLint is absent, because the step then printed a warning and skipped. The step now reports an `error:` and exits non-zero instead, and AGENTS' gate list names only the coverage gate and the Debug build, stating that every build runs strict SwiftLint and fails without it. A build started from the Xcode app does not inherit a shell's `PATH`, and SwiftLint's README says Homebrew's Apple Silicon directory "may not be in the Xcode search path", so the step appends `/opt/homebrew/bin` and `/usr/local/bin` to `PATH` before looking; without that, the change would have turned an Xcode-app build that used to skip lint into a failure on a machine where SwiftLint is installed. README's toolchain line states the rule.

**Evidence** (2026-09-24, Xcode 27.0, SwiftLint 0.65.1, Debug app builds in an isolated scratch copy regenerated per variant, each read from its build log). The candidate builds and lints 109 files. With the SwiftLint command renamed so it cannot be found, the candidate fails at the SwiftLint step with its error, while the previous skip branch under the same rename builds with its warning, which is the revert. Under a minimal `PATH` of `/usr/bin:/bin:/usr/sbin:/sbin`, the candidate still finds SwiftLint through the appended directory and lints all 109 files, while the previous script skips lint, which is the over-restriction check and the Xcode-app situation the appended path exists for. A vertical-whitespace violation in `Sources/SettingsKeys.swift` still fails the build. An `error:` line alone does not fail an Xcode build: printing it and exiting 0 builds successfully, so the non-zero exit is what enforces the rule. Dropping only the `exit 1` still fails, because the step then runs the missing command and exits 127; that mutant is equivalent in effect, and the explicit exit is kept so the failure names its cause.

**Gates:** `./check-coverage.sh` passed with 392 tests at 98.65% for Managers and 97.80% for application logic, and the Debug build with signing disabled succeeded, both from cleared DerivedData, each running SwiftLint with 0 violations. The only source warning is N7's. **Baseline:** the final gates of `2f1843a` on 2026-09-24; no source, test, or build configuration changed between that revision and this change. **Review:** an adversarial review (gpt-5.6-sol, unsandboxed) rebuilt the candidate from empty derived data, reran the build step under the minimal `PATH`, and returned no findings.
